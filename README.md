# Christmas Cards Hub

![Website Mockup](assets/images/readme/mockup.png)


## Overview
Christmas Cards Hub is a front-end web application designed during a Hackathon to bring joy and creativity to the holiday season. It allows users to create personalized Christmas cards with unique styles and features, including animations, sounds, and interactive elements.

## Features

- Fully responsive to all screensizes
- **User-Friendly Design**: Ensures smooth and enjoyable customization for every user.
- **Card Types**: A variety of card styles including:
  - Animated Cards
  - Cards with sound effects
  - Interactive Cards where users can input their details or control the card motion
- Modal Contact Form with Toast confirmation message



---

## How to Run
- Clone or download this repository
- Open index.html in your preferred browser
- No setup required — all external resources (Bootstrap, Google Fonts FontAwesome) load through CDN links
