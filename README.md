# 🎄 Christmas Cards Hub 🎄

## Project Overview

**Christmas Cards Hub** was built as part of a **front-end hackathon**.  
The website focuses on creativity, interactivity, and festive design, allowing users to:

- Browse different categories of Christmas cards
- Interact with animated and sound-enabled cards
- Personalize cards using user input
- Enjoy a playful and seasonal user experience

The website is live and can be viewed here:  
👉 **[Christmas Cards Hub – Live Demo](https://alakeldev.github.io/Christmas-Cards-Hub/index.html)**

## 🎨 Design

### Colour Scheme

The colour scheme for *Christmas Cards Hub* was carefully crafted to evoke feelings of warmth and festivity while maintaining a clean and professional design. Using a combination of snow-like whites, festive reds, lush greens, and subtle hues of grey, the design embraces the essence of the holiday season.

The background features soft gradients and textures resembling snowfall to immerse users in the Christmas spirit. White is used predominantly for text to ensure clarity and contrast against the darker and softer background tones. The festive green button on the landing section adds vibrancy and acts as a focal point, inviting users to interact with the site effortlessly.

Hover states in navigation elements were meticulously designed to add interactivity. When users hover over each element:
- A subtle underline animation appears to guide the visitor's attention to interactive components

This harmonious combination of festive colours, interactive animations, and textured backdrops delivers a joyful and engaging experience for users without overwhelming the visual appeal of the site. These colours help reinforce a holiday atmosphere while maintaining readability and accessibility.

![Colour Palette](assets/images/readme/color-palette.png)

### Typography
- Clean and readable fonts
- Clear hierarchy between headings, descriptions, and buttons
- Emphasis on friendliness and simplicity

### Imagery
- Festive imagery (Christmas decorations, illustrations, seasonal elements)
- Visual balance between text and images
- Cards designed to feel playful but with a commercial twist
